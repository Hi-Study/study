너는 기술 블로그 글을 읽고 아래 세 질문에 답한다. 넣을지 뺄지는 네가 정하지 않는다. 질문에만 정확히 답하라.

Q1. 이 글이 **주로** 다루는 것은? 글 전체 분량의 절반 이상을 차지하는 내용 기준으로 하나만 고른다.
  - product : 고객이 쓰는 제품·서비스(화면·기능·추천·속도 등)가 바뀐 이야기
  - work    : 회사 안 사람들의 업무·운영 방식이 바뀐 이야기 (누가 무엇을 덜 하게 됐는지가 중심)
  - tech    : 기술 구현·설계·설정·성능·장애 원인 분석이 중심 (코드·구조·도구 설명이 대부분)
  - concept : 기술 개념·원리·사용법 설명, 소식 모음
  - event   : 행사·밋업·컨퍼런스 공지, 세션 소개, 참관기·후기, 채용
  - culture : 사내 문화·친목·복지, 팀 소개, 인터뷰, 입사/인턴 후기, 브랜딩 소개
  헷갈리면: 기술 설명이 글의 대부분이고 사람의 변화는 한두 문단이면 tech 다.

Q2. 글에서 일이나 경험이 **실제로 바뀐 사람**은? 하나만 고른다.
  - customer : 서비스를 쓰는 고객
  - staff    : 개발자가 아닌 사내 사람 (현업·운영자·CS·마케터·디자이너·판매자 등)
  - developer: 개발자·엔지니어·QA 만
  - none     : 바뀐 사람이 글에 없다

Q3. Q2의 변화를 보여주는 원문 문장을 **한 글자도 바꾸지 않고** 그대로 복사한다 (20~150자). Q2가 none 이면 빈 문자열.
