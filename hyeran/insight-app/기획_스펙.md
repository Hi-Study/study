# 인사이트 — 기획·기능 스펙 (현행 v2)

> 이 문서는 **현재 구현된 프로토타입 기준**의 기능 명세다. 디자인 토큰·컴포넌트 스타일은 `design.md`가 담당하고, 이 문서는 **무엇을 / 어떻게 동작하는가(기능·데이터·규칙)**를 담는다.
> 구현 스택: Next.js(App Router) · Supabase(Postgres/Auth/RLS) · Gemini(요약).

---

## 1. 개요

**한 문장**: 기업 기술·기획 블로그의 좋은 글을 모아 읽고, 각자의 **인사이트**를 남겨 공유하는 모바일 커뮤니티.

**핵심 가치**: 글 자체보다 **"누가 이 글에서 무엇을 얻었는가(인사이트)"** 가 본질. → `인사이트` 탭이 서비스의 심장.

**사용자(인사이터)**: 기획자·디자이너·개발자 등 프로덕트 종사자. **구글 로그인**으로 누구나 가입.

**콘텐츠 소스**
- 시스템이 기업 블로그를 **자동 수집(크롤)** → AI 요약 자동 생성
- 수집되지 않은 글은 사용자가 **직접 등록**(URL) → 크롤링+AI 요약 자동, 등록 시 인사이트 필수

## 2. 용어

| 용어 | 의미 |
|---|---|
| **인사이트** | 글을 읽고 남기는 감상·배움 (3문항). *(구 "독후감" → 전면 "인사이트"로 변경됨)* |
| **인사이터** | 서비스 사용자 |
| **오늘의 글** | 최근 7일 인기 1위 글 (홈 최상단 히어로) |
| **읽음** | 상세를 90% 이상 스크롤한 상태 (완독) |
| **읽음 수** | 글별 완독 수 = 조회수(뷰수) 대체 지표 (별도 조회 추적 없음) |

## 4. 콘텐츠 소스 & AI

**자동 수집 파이프라인** (`scripts/collect.mjs`)
- 기업 RSS → 원문 추출(Readability) → 봇 차단(403 등) 시 RSS 본문(content:encoded)으로 폴백
- 본문은 **구조형 블록 배열**로 저장 (§7 posts.body 참조)
- Gemini 요약 → `problem`/`solution`/`learning`(각 한 문장) + `category` + `tags`

**직접 등록** (`/register`)
- URL 입력 → **중복 확인**(이미 등록된 글이면 안내) + 인사이트 3문항(최소 1개 필수)
- 등록 시 원문 크롤링 → 블록 본문 + AI 요약 + 카테고리/태그/기업 자동 판별 → 상세로 이동

**AI 요약 3문항** (상세 상단 카드)
1. 무슨 문제를 다뤘나 (problem)
2. 어떻게 해결했나 (solution)
3. 기획 관점에서 무엇을 배울 수 있나 (learning)

**카테고리**: 프로덕트 / 디자인 / 기술 / AI

## 5. 화면별 기능

### 5-1. 홈 — 4개 큐레이션 섹션 (위→아래)
1. **오늘의 글** — 최근 7일 (읽음 수 + 인사이트 수) 1위 **1편**. **매거진 히어로 카드**(큰 커버 이미지 + 하단 오버레이 제목). 커버 없으면 기업색 그라디언트+로고.
2. **인기 있는 글** — 인사이트 많은 **상위 8개**, **2열 그리드**.
3. **내가 북마크한 글** — 가로 스와이프 + **전체보기**(→ 피드 북마크 탭). 없으면 "북마크한 글이 여기 모여요" 안내.
4. **기업별 기술블로그** — 기업별로 헤더(로고·이름·**즐겨찾기 별**) + 최신 글 가로 스와이프 + **전체보기**(→ 피드 기업 필터).
- 섹션은 **넉넉한 간격**으로 구분(구분선 대신 여백).

### 5-2. 피드 — 기준 화면
- **언더라인 탭**: 전체 / 북마크
- **기업 필터 칩**: All · 팔로우 중 · 기업들(**더보기**로 6개 초과 펼침). 선택 = **브랜드색 채움**(비선택 = 흰 칩).
- **카테고리 칩**(영문 Product/Design/Tech/AI, 다중 선택)
- **2열 커버 카드 그리드**
- URL 파라미터: `?tab=bookmark`, `?company=<id>` 로 초기 필터 지정

### 5-3. 인사이트 탭 — 감상 피드
- **언더라인 탭**: 전체 / 북마크(내가 북마크한 글의 인사이트)
- **인사이트 카드**: 좌 글 썸네일 + 작성자·날짜 + 글 제목 + **Q&A 전체(길면 더보기/접기)** + 댓글 수
- 카드 클릭 → 상세로 이동하며 **해당 인사이트로 스크롤·강조(포커싱)**

### 5-4. 검색
- 실시간 필터(제목·기업·태그) → **리스트 로우** 결과
- **최근 검색어**(기기 저장, 개별 삭제) · **추천 검색어(문장형)** · **급상승 검색어**

### 5-5. 마이
- 프로필(아바타·이름) + **로그아웃**
- **3탭(개수 표시)**: 인사이트 남긴 글 / 댓글 단 글 / 하이라이트한 글 → **리스트 로우**

### 5-6. 글 상세
- 카테고리 바 + 제목 + 기업/작성자 + 날짜 + 태그
- **직접 등록 글**: 작성자 카드(아바타·이름·"직접 등록" 배지) 강조 / 본인이면 앱바에 **수정·삭제**(삭제 시 달린 인사이트·댓글 수 명시)
- **AI 요약 카드**(3문답)
- **원문 리더** (본문을 불러온 글):
  - **구조형 렌더** — 헤딩/문단/목록/인용/코드/이미지 위계 유지
  - **원문 링크**(↗) 제공
  - **문단 단위 하이라이트 + 메모**(아이콘→모달, 나만 보기)
  - 불러오지 못한 글은 원문 링크 카드만
- **인사이트(리뷰) 목록**:
  - 각 인사이트 = 작성자 + 3문답 + **인라인 "댓글 및 토론"**(입력창 + 댓글 + **대댓글** + **좋아요**)
  - 내 인사이트엔 **⋯ 점 메뉴 → 수정**
  - 내 인사이트가 없으면 상단에 "인사이트 쓰기" 버튼
- **읽음 처리**: 90% 스크롤 시 기록 · **북마크** 토글

### 5-7. 알림
- 종류: **새 글** / **인사이트 댓글**(내 인사이트에 댓글, 내 댓글에 답글)
- 탭(전체/새 글/인사이트 댓글) · 진입 시 읽음 처리

### 5-8. 로그인
- **구글 로그인 전용**. 미로그인 시 `/`(로그인) 외 접근 → 로그인으로 리다이렉트.

## 6. 핵심 규칙·로직

- **오늘의 글** = 최근 7일 글 중 (읽음 수 + 인사이트 수) 최대, 동률 시 최신. (7일 내 글 없으면 전체에서 선정)
- **인기 있는 글** = 인사이트 수 내림차순 → 동률 최신, 상위 8 (오늘의 글 제외)
- **읽음 수** = `reads` 완독 수 (뷰수 대체, 별도 조회 추적 안 함)
- **통일 카드 메타**(전 화면 공통): 이미지·북마크·제목·작성자/출처·읽음 수·인사이트 수·등록일
- **인사이트 = 글당 유저 1개** (수정 가능), 3문항 중 최소 1개 필수
- **비로그인 북마크 시도** → 로그인 안내 (현재는 전 화면 로그인 필수라 방어 코드)

## 7. 데이터 모델 (Supabase)

| 테이블 | 핵심 컬럼 | 비고 |
|---|---|---|
| `profiles` | id, name, initial | 구글 로그인 시 생성 |
| `companies` | slug, name, color, domain, rss_url | 기업(출처) |
| `posts` | title, url, category, tags, source(crawl/direct), author_id, ai_summary(problem/solution/learning), **body(블록 배열)**, parsed, published_at | 글 |
| `reviews` | post_id, author_id, q1/q2/q3, is_draft | 인사이트 (글당 유저 1개) |
| `comments` | review_id, author_id, **parent_id**, body | 댓글·대댓글 |
| `comment_likes` | comment_id, user_id | 댓글 좋아요 |
| `bookmarks` | user_id, post_id | 북마크 |
| `favorites` | user_id, company_id | 기업 즐겨찾기 |
| `highlights` | user_id, post_id, **sentence_idx(=블록 인덱스)**, memo | 문단 하이라이트/메모 |
| `reads` | user_id, post_id | 완독(읽음) |
| `notifications` | user_id, type(new_post/comment), title, body, read | 알림 |

**posts.body 블록 포맷** (구조형 리더용): `string[]`, 각 항목이 타입 접두어를 가짐
`::h2::` 소제목 · `::h3::` 하위 소제목 · `::p::` 문단 · `::li::` 목록 · `::quote::` 인용 · `::code::` 코드 · `::img::URL` 이미지 · `::cap::` 캡션. (접두어 없는 구식 항목은 문단으로 처리)

**RLS**: 공용 콘텐츠는 로그인 유저 읽기, 쓰기는 본인 것만. 자동 수집은 서비스 롤로 삽입.
