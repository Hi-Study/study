# 인사이트 공유 서비스 (가명: 어노테이션) — 기획 스펙 v1

> **용도**: 이 문서를 Lovable / Bolt.new / v0.dev / Claude에 통째로 붙여넣으면 클릭 가능한 모바일 프로토타입이 생성됩니다. 동시에 팀 내 기획 기준 문서로 사용합니다.
>
> **이전 스펙(어노테이션 v2/v3)과의 방향 전환 (major pivot)**:
> - **로그인**: 초대 코드 기반 폐쇄형 → **구글 로그인**만 지원 (누구나 가입)
> - **핵심 콘텐츠 용어**: "사유" → **"독후감"** (글을 읽고 남기는 감상·인사이트)
> - **정보 구조 축**: 원문 어노테이션 중심 → **기업(기술 블로그) + 카테고리** 중심 탐색
> - **탭 구조 확장**: 홈 / 검색 / 마이 (3탭) → **홈 / 피드 / 인사이트 / 검색 / 마이 (5탭)**
> - **AI 요약**을 상세 페이지 핵심 요소로 상시 제공 (3가지 관점)
> - **독후감**은 3개 질문으로 재구성, 글 등록 시 필수

---

## 1. 프로젝트 요약

**한 문장**: 기업 기술/기획 블로그의 좋은 글을 모아 읽고, 각자의 **독후감(인사이트)** 을 남겨 공유하는 커뮤니티 앱.

**핵심 가치**: 글 자체보다 **"누가 이 글에서 무엇을 얻었는가(독후감)"** 가 본질. → `인사이트` 탭이 서비스의 심장.

**사용자(인사이터)**: 기획자·디자이너·개발자 등 프로덕트 종사자. 구글 로그인으로 누구나 가입.

**콘텐츠 소스**:
- 시스템이 기업 블로그를 수집(크롤링)해 자동 등록 → AI 요약 자동 생성
- 수집되지 않은 글은 사용자가 **글 등록**으로 직접 공유 (등록 시 독후감 필수)

**플랫폼**: 모바일 웹 (뷰포트 360–390px 기준)
**결과물(프로토타입 범위)**: 클릭 가능한 정적 프로토타입, 로컬 state만 사용 (실제 로그인·크롤링·AI 호출은 시뮬레이션)

## 2. 사용자가 할 수 있는 액션 (7가지)

| # | 액션 | 위치 |
|---|------|------|
| 1 | 올라온 글에 **독후감** 남기기 | 글 상세 / 글 등록 |
| 2 | 올라온 **독후감에 댓글** 남기기 | 인사이트 · 글 상세 |
| 3 | **글 등록** 하기 (등록 시 독후감 **필수**) | FAB(+) |
| 4 | **북마크** | 글 상세 · 카드 |
| 5 | 글 **하이라이트 및 메모** | 글 상세(원문) |
| 6 | **선호 기업 즐겨찾기** | 온보딩 · 기업 칩 · 마이 |
| 7 | **검색** | 검색 탭 |

**로그인은 구글 로그인만 지원.** (이메일/비밀번호·초대코드 없음)

## 3. 정보 구조 & 네비게이션

**하단 탭 5개**: 홈 · 피드 · 인사이트 · 검색 · 마이
**전역 진입**: FAB(+) = 글 등록

```
[로그인] 구글 로그인 → 바로 홈
   ↓
[홈]
   ├─ 상단: 추천 글(없으면 미노출)
   ├─ 중단: 기업별 칩(다중 선택, default 전체)
   ├─ 하단: 기업별 글 스와이프(기업명 옆 ★ 즐겨찾기 토글, 칩 선택 시 동적 변경)
   ├─ 카드 탭 → [글 상세]
   └─ FAB(+) → [글 등록]

[글 상세]
   ├─ AI 요약(3관점) → 원문 → 독후감
   ├─ 기업 로고 탭 → [피드]로 이동(해당 기업 선택 상태)
   ├─ 원문 문장 탭 → 하이라이트/메모
   ├─ 북마크 토글
   ├─ 독후감 남기기 → 인사이트에 반영
   └─ 독후감에 댓글

[피드] 전체 탭 / 북마크 탭
   ├─ 필터: 기업별 칩 + 카테고리 칩(프로덕트·디자인·기술·AI)
   ├─ 전체 글 최신순
   ├─ 스크롤 90% 도달 글 → "다 읽음" 배지
   └─ 카드 탭 → [글 상세]

[인사이트]  ← 핵심 가치
   ├─ 독후감 최신순(글이 아닌 독후감 단위)
   ├─ "어떤 글에 · 누가 · 어떤 독후감" 카드
   └─ 독후감 카드 → 댓글 보기/작성

[검색]
   ├─ 상단: 최근 검색어
   ├─ 중단: 추천 검색어(질문/짧은 동사구)
   ├─ 하단: 급상승 검색어 Top 10
   └─ 결과 카드 → [글 상세]

[마이]
   ├─ 인사이트 남긴 글(독후감 남긴 글, 임시저장은 "작성중" 배지)
   ├─ 댓글단 글
   └─ 하이라이트 남긴 글

[알림] (홈 종 아이콘)
   └─ 알림 리스트(내 독후감 댓글 · 즐겨찾기 기업 새 글)

[글 등록]
   ├─ URL 입력 → 중복 확인 → [확인][등록 글 보기]
   ├─ 독후감(3개 질문) — 필수
   └─ 등록 → 홈/피드에 반영
```

## 4. 화면별 상세 스펙

### 4.0 로그인

- **로그인**: 로고 + 카피 + **[구글로 계속하기]** 단일 버튼 → 바로 홈. (별도 온보딩 단계 없음)
- 구글 로그인만 지원.
- **기업 즐겨찾기는 홈 기업 섹션의 별(★) 토글로 지정/해제**(§4.1 참조).

### 4.1 홈

**목적**: 추천 글과 기업별 최신 글을 한눈에.

- **상단 헤더**: 좌 로고/“홈”, 우 종(알림) 아이콘
- **상단 — 추천 글 섹션** (있을 때만 노출)
  - 추천 기준: 내가 **독후감·댓글·북마크한 글의 태그**와 유사한 글
  - 가로 스와이프 카드 or 강조 카드
  - 추천 대상이 없으면 섹션 자체를 숨김
- **중단 — 기업별 칩** (다중 선택, default: **전체**)
  - 즐겨찾기한 기업이 앞쪽 정렬
  - 칩 선택 시 하단 스와이프 목록이 동적으로 필터링
- **하단 — 기업별 글 스와이프**
  - 기업 단위 섹션(로고 + 기업명 + **즐겨찾기 별 토글**) + 각 기업 최신 글 가로 스와이프
  - 기업명 옆 ★ 토글로 즐겨찾기 지정/해제 → 해당 기업 새 글 알림 + 칩 앞쪽 정렬
  - 칩 선택 상태에 따라 노출 기업/글 변경
- **FAB(+)**: 글 등록
- **하단 탭 바**

### 4.2 글 상세

**목적**: AI 요약으로 빠르게 파악 → 원문 읽기 → 독후감 남기기.

**위→아래 순서**
1. 제목 · 기업 로고·기업명 · 공유자 · 날짜
2. **키워드 태그**
3. **AI 요약 카드** — 3가지 관점 고정
   - 무슨 문제를 다뤘나?
   - 어떻게 해결했나?
   - 기획 관점에서 무엇을 배울 수 있나?
4. **원문 본문** (문장 단위) — 하이라이트/메모 인라인
5. **독후감 섹션** — 이 글에 달린 독후감들 (작성 CTA 포함)

**인터랙션**
- **기업 로고 탭** → 피드로 이동하며 해당 기업이 선택된 상태
- **문장 탭** → 하이라이트 토글 + 메모(**나만 보기**, 비공개)
- **원문이 없는 글**(사용자 등록 등 파싱 불가)은 하이라이트/메모 불가 → 원문 링크 카드만 노출
- **북마크** 토글(상단)
- **독후감 남기기** → 3개 질문 폼(§4.9와 동일 구조) → 게시 시 인사이트 탭·마이에 반영
- **독후감 → 댓글** 보기/작성

### 4.3 피드 — 전체 탭 / 북마크 탭

**목적**: 전체 글을 최신순으로 탐색 + 필터링.

- **상단 세그먼트**: 전체 / 북마크
- **필터 영역**:
  - 기업별 칩(다중 선택)
  - 카테고리 칩: **프로덕트 · 디자인 · 기술 · AI**
- **리스트**: 전체 글 최신순 정렬(카드)
- **다 읽음 배지**: 글 상세에서 **스크롤 90%** 도달 시 해당 글에 "다 읽음" 배지 부여 → 피드 카드에 표시
- **북마크 탭**: 북마크한 글만, 동일 필터 적용

### 4.4 인사이트 (핵심 가치)

**목적**: 올라온 **독후감**을 최신순으로 확인.

- **노출 단위 = 독후감** (글 단위 아님)
  - "**{글 제목}** 에 · **{인사이터}** 가 남긴 독후감"
  - 독후감 본문(3개 질문 답변) 요약 노출
  - 원 글로 이동하는 링크(기업/제목)
- **댓글**: 독후감 단위로 댓글 지원(카드 탭 → 댓글 리스트 + 입력)
- 정렬: 최신순

### 4.5 검색

**목적**: 관심사를 쉽게 발견.

- **검색바**: pill 형태
- **상단 — 최근 검색어**: 최근 입력 기록 + 개별 삭제
- **중단 — 추천 검색어**: 내 **독후감·댓글·북마크한 글의 태그** 기준
  - 문구 형식: "~를 찾으시나요?" 질문 또는 짧은 동사구
- **하단 — 급상승 검색어**: 검색어 순위 **Top 10**
- **결과**: 매칭 카드 리스트 → 글 상세

### 4.6 마이

**목적**: 내 활동 모아보기.

- **프로필 섹션**: 아바타 + 이름 + 서브 라벨, 설정 아이콘
- **세그먼트 3개**
  - **인사이트 남긴 글**: 독후감을 남긴 모든 글. 임시저장은 **"작성중" 배지**
  - **댓글단 글**: 댓글 남긴 글 목록
  - **하이라이트 남긴 글**: 하이라이트한 글 목록

### 4.7 알림 (홈 종 아이콘)

**목적**: 내 활동 관련 알림 확인.

- **알림 리스트**: 내 독후감에 달린 댓글, 즐겨찾기 기업의 새 글 등
  - 안읽음 dot 표시, 화면 진입 시 읽음 처리
- (기업 즐겨찾기 지정은 홈에서 함 — §4.1)

### 4.8 글 등록

**목적**: 아직 수집되지 않은 기사·블로그 글을 직접 공유.

- **URL 입력**
  - URL 붙여넣기 인풋
  - **중복 확인**: 이미 올라온 글이면 안내 + [확인] [등록 글 보기]
- **(자동)** 등록 후 제목·기업·태그·AI 요약은 시스템이 채움(프로토타입에선 시뮬레이션)
- **독후감(필수) — 3개 질문**
  - Q1. 인상 깊은 부분이 무엇이었나요?
  - Q2. 업무에 어떻게 적용할 수 있나요?
  - Q3. 인사이터들에게 하고 싶은 질문이 있다면?
- **하단**: [임시저장] / [등록] (독후감 조건 충족 시 활성 — §열린질문 참조)

### 4.9 독후감 작성 폼 (공통 컴포넌트)

- 3개 질문(위 Q1~Q3), 각 textarea
- 글 등록 시 = 필수 / 기존 글에 다는 경우도 동일 폼
- 게시 시: 인사이트 탭 최신순 상단, 마이 "인사이트 남긴 글"에 반영

## 5. 핵심 개념 정의

| 용어 | 정의 |
|------|------|
| **인사이터** | 서비스 사용자 |
| **글** | 기업 블로그 글(수집) 또는 사용자가 등록한 외부 글 |
| **기업** | 글의 출처(기술/기획 블로그 운영 주체). 로고로 식별 |
| **카테고리** | 프로덕트 · 디자인 · 기술 · AI (4개 고정) |
| **키워드 태그** | 글별 세부 주제 태그(AI/시스템 생성) — 추천 로직의 기준 |
| **독후감** | 글을 읽고 남기는 3문항 감상. 서비스 핵심 콘텐츠 |
| **댓글** | 독후감에 다는 반응 |
| **하이라이트/메모** | 원문 문장에 남기는 개인 표시·메모 |
| **다 읽음** | 글 상세 스크롤 90% 도달 시 부여 |

**추천 로직(공통)**: 홈 추천 글 · 검색 추천 검색어 = 내가 **독후감/댓글/북마크한 글의 태그**와 유사도가 높은 항목.

## 6. 샘플 데이터 (프로토타입용)

### 6.1 기업 (출처)
토스 · 우아한형제들(배민) · 카카오 · 당근 · 네이버 · 라인 — 각 로고 플레이스홀더(이니셜/색상 원형)

### 6.2 카테고리
프로덕트 · 디자인 · 기술 · AI

### 6.3 인사이터
- 다람쥐(본인, "다") · 김민수("김") · 이지현("이") · 박지훈("박")

### 6.4 글 (예시)
- **G1** 제품 우선순위, 얼마나 자주 재조정해야 할까 · 토스 · 카테고리: 프로덕트 · 태그: 우선순위, 로드맵
- **G2** 사용자 인터뷰 인사이트 정리 5가지 · 당근 · 디자인 · 태그: 리서치, UX
- **G3** OKR 실행 시 흔한 함정 7가지 · 우아한형제들 · 프로덕트 · 태그: OKR, 조직
- **G4** LLM 프로덕트에 RAG 적용기 · 카카오 · AI · 태그: RAG, LLM
- **G5** 디자인 시스템 토큰 운영 · 네이버 · 디자인 · 태그: 디자인시스템

각 글: AI 요약(3관점), 키워드 태그, 독후감 0~N개.

### 6.5 독후감 (인사이트 탭 노출)

## 7. 디자인 가이드

> **디자인의 단일 기준(Source of Truth)은 [`design.md`](design.md)** 입니다. 색·타이포·간격·컴포넌트 토큰은 모두 그 문서를 따릅니다. 아래는 요약.

- **면(Surface) 반전**: 흰 배경 + 회색 카드(`--card #F2F2F2`), **보더·그림자 없음**
- **색은 상태·분류를 뜻함** — 화면당 채도 높은 필은 하나. 액센트: `--blue #056DFF`(활성/선택), `--orange #C75300`(내 참여), `--lime/--sky`(분류 바 전용, 텍스트 금지)
- **좌측 3px 카테고리 바** + 우상단 상태 배지(카드당 1개)
- **타이포**: 본문/UI = Pretendard 400·500만, 메타(URL·날짜·숫자) = JetBrains Mono. 22px↔11px 스케일 점프
- **FAB**: 액센트 아님, `--text` 다크 필
- **다크모드 지원**, 모션(stagger 진입 등), 카피 규칙(동사 먼저·마침표/느낌표 없음) — 세부는 `design.md` §3~9

## 9. 인터랙션 규칙 (프로토타입 범위)

- 모든 화면 이동은 로컬 라우팅(useState)
- 기업 칩/카테고리 칩: 선택 배열 add/remove, 목록 동적 필터
- 하이라이트: 문장 탭 → boolean 토글, 메모는 문장에 연결된 텍스트
- 북마크/즐겨찾기: boolean 토글
- 독후감 게시: 3문항 입력 → 인사이트/마이 반영 (필수 조건은 §10 확인)
- 댓글: 독후감 단위 배열에 추가
- 다 읽음 배지: 상세 스크롤 90% 도달 감지 → 해당 글 flag
- 기업 로고 탭: 피드로 이동 + 해당 기업 선택 상태 전달
- 추천/추천검색어: 내 태그 집합 기반 하드코딩 매칭

## 10. 확정된 결정 (2026-08-08)

1. **독후감 필수 조건**: 3개 질문 중 **최소 1개** 이상 작성 시 게시 가능. ✅
2. **기업 즐겨찾기**: 별도 온보딩 없이 **홈 기업 섹션의 ★ 토글로 지정/관리**. 즐겨찾기 기업의 새 글을 알림으로 받음. ✅
3. **하이라이트/메모**: **나만 보기(비공개)**. 원문이 없는 글에서는 하이라이트/메모 불가. ✅
4. **댓글**: **독후감에만** 단다(글 자체에는 댓글 없음). ✅
5. **알림 화면**: **포함**(홈 종 아이콘 → 알림 + 기업 즐겨찾기). ✅
6. **검색 대상**: 글 제목·기업·태그. **독후감 본문은 검색 미포함**. ✅

## 11. 최종 프롬프트 (복사용)

> 첨부한 스펙에 따라 클릭 가능한 모바일 웹 프로토타입을 만들어주세요.
>
> **기술**: React + Tailwind, 단일 페이지, 화면 이동은 useState. 데이터는 §6 샘플을 하드코딩. Tabler Icons. 데스크탑에선 360–390px 폰 프레임, 모바일 풀스크린, 라이트 모드.
>
> **탭**: 홈 · 피드 · 인사이트 · 검색 · 마이 + FAB(글 등록). 로그인은 [구글로 계속하기] 클릭 시 온보딩(선호 기업 선택)으로.
>
> **핵심 동작**
> - 홈: 추천 글(없으면 숨김) + 기업 칩(다중, default 전체) + 기업별 글 스와이프(칩 선택 시 동적 변경)
> - 글 상세: AI 요약 3관점(문제/해결/기획 배움) + 원문(문장 탭 하이라이트) + 독후감 + 기업 로고 탭 시 피드로 이동(기업 선택 상태)
> - 피드: 전체/북마크 탭, 기업·카테고리(프로덕트/디자인/기술/AI) 필터, 최신순, 스크롤 90% 시 "다 읽음" 배지
> - 인사이트: 독후감 단위 최신순, 독후감에 댓글
> - 검색: 최근/추천(내 태그 기준)/급상승 Top10
> - 마이: 인사이트 남긴 글(임시저장 "작성중" 배지)/댓글단 글/하이라이트 남긴 글
> - 글 등록: URL 중복 확인 [확인][등록 글 보기] + 독후감 3문항(필수)
>
> 모든 인터랙션이 실제 동작하고, URL 하나로 전체 플로우를 클릭으로 따라갈 수 있어야 합니다.
