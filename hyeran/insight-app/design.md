# 인사이트 — Design System

> 기업 기술블로그 글을 읽고 나의 인사이트를 나누는 **모바일 우선** 한국어 서비스.
> MiniMax의 절제된 시각 언어에 **롱블랙식 에디토리얼 톤**(각짐·완전 플랫·큰 제목·매거진 히어로)을 더한 결과물이다.
> 구현: `src/app/globals.css`(토큰·컴포넌트 클래스), `src/components/*`(마크업).

## Overview

인사이트는 **스타크 모노크롬(화이트 캔버스 + 검정 잉크)** 위에 **코랄 한 색**만 아껴 쓰는 절제된 언어를 쓴다. 검정(`{colors.primary}` = `#000`/`{colors.ink}`)이 대표 CTA이고, 코랄(`{colors.cat-ai-fg}` = `#FF4A28`)은 "지금 주목" 순간 — NEW 뱃지, FAB, 활성 즐겨찾기·활성 좋아요, 원문 하이라이트 — 에만 등장한다. 파랑(`{colors.blue-info}`)은 링크/정보 보조로 강등된다. **롱블랙식 에디토리얼 톤**: 카드·이미지는 **각지고(radius 0) 완전 플랫**, 제목은 **700 near-black**.

**피드가 기준 화면**이다. 목록은 **이미지 중심 커버 카드**(커버 + 북마크 + 제목 + 통일 메타)를 **2열 그리드**로 구성하고, 다른 모든 화면이 이 카드 언어·색·타이포를 따른다. 이미지가 없는 글은 **기업 브랜드색 그라디언트 플레이스홀더**로 채워 카드 리듬을 유지한다.

홈은 **네 개 큐레이션 섹션**으로 위계를 만든다(위→아래): ① **오늘의 글** — 최근 7일 인기 1위 한 장을 **매거진 히어로**(큰 커버 이미지 + 하단 오버레이 제목)로, ② **인기 있는 글** — 인사이트 상위 **8개**를 **2열 그리드**로, ③ **내가 북마크한 글** — **가로 스와이프(+전체보기)**로, ④ **기업별 기술블로그** — 기업별 최신을 **가로 스와이프(+전체보기)**로. 각 섹션은 **큰 제목 + 설명 한 줄 + 넉넉한 여백(56px)**으로 구분한다(구분선 없음).

서체는 **Pretendard 단일 서체**를 모든 역할에 쓴다. 디스플레이·본문·라벨·**뱃지·아이콘 옆 메타 문구**까지 전부 Pretendard 하나로 통일한다(별도 라틴/모노 서체 없음).

**Key Characteristics**
- 모노크롬(화이트 `{colors.canvas}` + 검정 `{colors.primary}`)에 코랄 `{colors.cat-ai-fg}` 단일 포인트
- 검정 알약 = 대표 CTA. 브랜드색은 정체성 순간에만
- **피드(기준 화면)**: 이미지 중심 커버 카드 — 커버 + 북마크 + 제목 + 통일 메타, **2열 그리드**
- 홈 4섹션: 오늘의 글(매거진 히어로 1장) → 인기 있는 글(인사이트 8개, 2열) → 내가 북마크한 글(스와이프+전체보기) → 기업별 기술블로그(스와이프+전체보기). **큰 제목+설명+넉넉한 여백**으로 구분
- **통일 카드 메타** (커버 카드·리스트 로우 2변형): 이미지·북마크·제목·작성자/출처·읽음 수·인사이트 수·등록일 — 밀도만 다르고 메타·토큰은 동일. 검색·마이는 리스트형(썸네일)
- **혼용 라벨**: 로고·카테고리는 영문(INSIGHT. / Product·Design·Tech·AI), 탭·본문은 한글
- 실제 기업 로고(인라인 SVG 마크)
- **Pretendard 단일 서체** — 모든 텍스트(뱃지·메타 포함)
- 480px 모바일 셸 + 상단 알림 벨 + 하단 탭바(홈/피드/인사이트/마이) + 우하단 FAB
- **각짐 규칙**: 카드·커버·썸네일·히어로는 **각짐(radius 0)**, 버튼/칩/탭/배지/아바타/검색 pill은 **알약(`{rounded.full}`)** 유지

> **이번 디자인 리프레시에서 그대로 유지(변경 안 함):** 상단 앱바의 **알림 벨**, **하단 탭바**(홈·피드·인사이트·마이), 기존 **검색바 위치**. 레퍼런스의 헤더-내 검색 이동이나 Feed/Explore/Saved/Settings 하단 네비게이션은 채택하지 않는다.

## Colors

### Brand & Accent
- **Coral** (`{colors.cat-ai-fg}` = `#FF4A28`): 유일한 브랜드 포인트. NEW 뱃지, FAB, 활성 즐겨찾기·활성 좋아요, 원문 하이라이트, 오늘의 글 뱃지. 과용 금지.
- **Blue Info** (`{colors.blue-info}` = `#056DFF`): 링크·정보 보조. 주요 CTA 아님.

### Ink & Surface
- **Primary / Ink** (`{colors.primary}` = `#000000`, `{colors.ink}` = `#161616`): 대표 CTA 배경, 헤드라인.
- **Canvas** (`{colors.canvas}` = `#FFFFFF`): 페이지·카드 기본 배경.
- **Surface** (`{colors.surface}` = `#F4F5F7`): 검색 pill, AI카드·작성자카드, 읽음 뱃지, 코드 블록.
- **Hairline** (`{colors.hairline}` = `#E9EAEE`): 카드 1px 테두리, 구분선, 앱바 하단선.

### Text
- **Charcoal** (`{colors.charcoal-text}` = `#2A2A2A`): 본문.
- **Steel** (`{colors.steel-text}` = `#6B7280`): 보조·메타·비활성 탭·라벨.
- **Stone** (`{colors.stone-text}` = `#9AA0AB`): 뮤트 캡션.

### Category — **11개**, 색은 **4계열** (v2.4)
카테고리 칩·라벨은 **한글 11개**. 하지만 11색은 식별 불가하므로 **좌측 3px 바·배지 색은 4계열 그룹**으로만 부여한다(`catGroup`/`catFg` in `types.ts`).

| 계열 | 카테고리 | 바 색 | 배지 글자색 |
|---|---|---|---|
| 프로덕트 | 프로덕트 · 비즈니스 | `--blue` | `#2563EB` |
| 디자인 | UIUX · 디자인 | `--orange` | `#C2410C` |
| 개발 | 프론트엔드 · 백엔드 · 데이터베이스 · 보안 · 모바일 | `--lime` | `#3F7A00` |
| 데이터·AI | AI · 데이터 분석 | `--sky` | `#0E7490` |

- 좌측 바 = 계열 원색(`CAT_COLOR`), 배지(`qc-cat`) = surface 배경 + 계열 글자색.
- 색은 "정확히 어떤 카테고리인지"가 아니라 "대략 어느 갈래인지"를 알려주는 장치.

### Semantic
- **Success** — bg `{colors.success-bg}` `#E7F6EC` / text `{colors.success-text}` `#127A3E` (읽음 등)
- **Read (중립)** — bg `{colors.surface}` / text `{colors.steel-text}`

### Dark Mode
`prefers-color-scheme:dark`에서 배경·카드·잉크 반전. 검정 CTA는 화이트 알약으로 반전. 코랄·검정 대비는 다크에서도 유지. 정식 다크 팔레트는 추후.

## Typography

### Font Family — **Pretendard 단일 서체**
모든 역할(디스플레이·히어로·앱바 로고·본문·라벨·카드 제목·기업명·**아이브로우/뱃지**·버튼·**메타(아이콘 옆 문구)**)을 **Pretendard** 하나로 처리한다.

```
"Pretendard","Pretendard Variable",-apple-system,BlinkMacSystemFont,"Apple SD Gothic Neo",sans-serif
```

> DM Sans, JetBrains Mono는 **사용하지 않는다**(사용자 결정). 레퍼런스가 hero/appbar에 DM Sans, eyebrow/meta에 JetBrains Mono를 지정했더라도 전부 Pretendard로 통일한다. 숫자 정렬이 필요한 곳(수치 메타)은 `font-variant-numeric: tabular-nums`로 보정한다. 기업 로고 SVG 내부 워드마크는 브랜드 자산이므로 예외.

### Hierarchy (전부 Pretendard)

| Token | Size | Weight | Line H | Letter Sp | Use |
|---|---|---|---|---|---|
| `{typography.appbar}` | 21px | 600 | 1.30 | -0.5px | 앱바 로고·타이틀 |
| `{typography.display-title}` | 20px | 600 | 1.30 | -0.5px | 상세 제목, 기업 헤더명 |
| `{typography.hero}` | 19px | 600 | 1.20 | -0.4px | 히어로/강조 타이틀 |
| `{typography.card-title}` | 15px | 600 | 1.40 | -0.3px | 카드 제목 |
| `{typography.company-name}` | 15px | 600 | 1.30 | 0 | 기업명 |
| `{typography.body}` | 15px | 400 | 1.72 | 0 | 원문 본문 |
| `{typography.body-sm}` | 13.5px | 400 | 1.60 | 0 | AI 답변, 입력값 |
| `{typography.label}` | 12px | 600 | 1.40 | 0 | 폼 라벨, 섹션 타이틀 |
| `{typography.button}` | 14px | 600 | 1.40 | 0 | 버튼·칩 라벨 |
| `{typography.eyebrow}` | 10px | 600 | 1.00 | 0.1em | 카테고리 아이브로우·뱃지 (Pretendard, UPPERCASE 느낌은 자간으로) |
| `{typography.meta}` | 11px | 400 | 1.40 | 0 | 메타·수치·도메인 (아이콘 옆 문구, Pretendard) |

### Principles
- **단일 서체**: Pretendard 하나로 전 역할. 위계는 크기·무게(400/500/600/700)·색으로만.
- 이탤릭 없음. 강조는 weight.
- 숫자 정렬 구간은 `tabular-nums`.
- 본문 line-height 1.72로 한글 장문 가독 확보.

## Layout

- **셸**: `{spacing.max-width}` 480px 중앙 정렬. 상단 앱바 + 하단 탭바 + 우하단 FAB.
- **Spacing**: base `{spacing.base}` 4px. 페이지 좌우 `{spacing.page-margin}` 15px. **홈 섹션 간 56px**. 카드 패딩 `{spacing.card-p}` 14px.
- **섹션 구분**: 구분선 대신 **넉넉한 여백(56px) + 큰 제목/설명**으로 나눈다(구분선 미사용).
- **카드 간격**: 2열 그리드 row-gap 26px·column-gap 14px. 가로 스와이프 gap 14px.
- **홈 구조**: 앱바(로고·알림) → 검색 pill → `hsec` **오늘의 글**(매거진 히어로 1장) → `hsec` **인기 있는 글**(2열 그리드) → `hsec` **내가 북마크한 글**(스와이프+전체보기) → `hsec` **기업별 기술블로그**(스와이프+전체보기).

## Shapes

**롱블랙식 전환**: 카드·이미지 계열은 **각짐(0)**, 인터랙션 요소만 알약. `--r-card`·`--r-hero` = **0**.

| Token | Value | Use |
|---|---|---|
| `{rounded.card}` | **0** | 카드·커버·썸네일·히어로 (각짐) |
| `{rounded.input}` | 10px | 입력/텍스트에어리어 |
| `{rounded.full}` | 9999px | 버튼·칩·탭·뱃지·검색 pill·FAB·아바타 (알약 유지) |

## Elevation

flat 기본. 커버 카드는 **테두리·그림자 없이 완전 플랫**(이미지가 카드를 정의). 떠 있는 요소에만 그림자.
- 커버 카드(`fcard`): 배경·테두리·그림자 없음. 제목·메타는 지면 위에 직접.
- 리스트 로우(`lrow`)·인사이트 카드(`review`): 행 사이 `{colors.hairline}` 1px 또는 여백.
- FAB: 코랄 + `0 6px 18px rgba(255,74,40,.42)`.
- 매거진 히어로: 큰 커버 이미지 + **하단 다크 그라디언트 스크림**(제목 가독).
- 모달·드로어: `0 12px 40px rgba(0,0,0,.28)`.

## Components

### Buttons — 전부 알약
- **`button-primary`**: 검정 알약. bg `{colors.ink}`, text `{colors.on-primary}`, `{rounded.full}`. 비활성 bg `{colors.surface}`.
- **`button-outline`**: bg `{colors.canvas}`, `1px solid {colors.ink}`, `{rounded.full}`.
- **`button-google`**: bg `{colors.canvas}`, `1px solid {colors.hairline}`, `{rounded.full}`.
- **`fab`**: 56px 원형. bg `{colors.cat-ai-fg}` 코랄. 우하단 고정, 탭바 위.

### Feed — 기준 화면 (이미지 중심)
서비스의 **기준 화면**. 모든 목록 UI는 이 카드 언어를 따른다.

- **Feed Header** — `INSIGHT.`(대문자, 코랄 점) 워드마크 + 알림 벨, 하단 하드라인. (햄버거 드로어는 추후.)
- **Underline Tabs (`utabs`)** — 전체 / 북마크. 활성 = 검정 텍스트 + 2px 하단바(`{colors.ink}`), 비활성 = 스틸. **피드·인사이트 탭 공통**(알약 seg 아님).
- **Company Filter Chips (`cchip`)** — **줄바꿈(wrap)**, 배타 선택. 기본 6개만 보이고 **`더보기 +N`**(점선 칩)으로 전체 펼침.
  - `All` / `팔로우 중`: 아웃라인 알약, 활성 시 검정 채움.
  - 회사 칩: **비선택 = 흰 칩 + 테두리**(색 없음), **선택 = 브랜드색 채움**(`company.color`) + 대비 텍스트 자동(`readableText`). 팔로우 회사엔 ★. **점·보더 링은 쓰지 않는다**(채움 자체가 선택 신호 — 크기 변화 없음).
- **Category Filter Chips (`katchip`)** — **영문** 아웃라인 알약(Product/Design/Tech/AI), 다중 선택, 활성 = 검정.
- **Feed Card (`fcard`)** — 이미지 중심, 각짐.
  - 커버(`fcard-cover`, 16:9): 커버 이미지(body 첫 `::img::`). 오버레이 — **북마크 토글**(`card-bm.cover`, 우상단) · 기업 뱃지(`fcard-co`, 좌하단, 브랜드색+대비 텍스트) · 읽음(`fcard-read`, 좌상단).
  - 본문(`fcard-body`): 제목 17px/**700 near-black** 2줄 클램프(에디토리얼 톤) + **통일 카드 메타**(작성자/출처 · 읽음 수 · 인사이트 수 · 등록일).
  - 카드: **각짐(radius 0) + 완전 플랫**(테두리·그림자 없음). 이미지가 카드를 정의하고 제목·메타는 지면 위에 얹힌다(롱블랙 톤). 제목·리스트 로우 제목은 **700**.
- **Cover Placeholder (`fcard-cover.ph`)** — 이미지 없는 글: **기업 브랜드색 그라디언트**(밝은→어두운) + 가운데 큰 기업 로고(옅게).

> **통일 카드 메타 (전 화면 공통)**: 이미지 · 북마크 · 제목 · **작성자**(직접 등록)/**출처**(기업) · **읽음 수** · **인사이트 수** · **등록일**. 메타 세트는 전 화면 공통이되, 표현은 **밀도 2변형**으로 나눈다 — **커버 카드**(`fcard`, 16:9 이미지 · 홈·피드)와 **리스트 로우**(`lrow`, 작은 썸네일 목록 · 검색·마이). 두 변형은 **같은 토큰·같은 메타**를 쓰는 한 가족이라, 밀도만 다르고 인상은 하나다.
> **조회수(뷰수)는 별도 추적하지 않는다** — 조회 로그 대신 `reads`(스크롤 90% 완독) 수를 "읽음 수"로 표기해 뷰수 자리를 대체한다. 레퍼런스의 평점(★)·시간제한 카운트다운은 도입하지 않는다.

### 홈 섹션 헤더 (`hsec`)
각 큐레이션 섹션은 **큰 제목(`hsec-title` 21px/700) + 설명 한 줄(`hsec-sub` 12.5px, 스틸)**을 갖는다. 섹션 간 **56px 여백**으로 구분(구분선 없음). 우측에 필요 시 `전체보기`.
- 오늘의 글 · "최근 일주일 가장 많이 읽힌 글"
- 인기 있는 글 · "인사이트가 많이 쌓인 글"
- 내가 북마크한 글 · "저장해 둔 글 모아보기"
- 기업별 기술블로그 · "기업별 최신 글 모아보기"

### 오늘의 글 (`feature`) — 매거진 히어로
최근 7일 내 글 중 **인기 1위 한 장**만 노출(유저 무관). 인기도 = **읽음 수 + 인사이트 수** 합, 동률 시 최신. **큰 커버 이미지(min-height 360px) + 하단 다크 그라디언트 + 큰 제목(24px/700)** 의 매거진 스타일. 단일 장(캐러셀 없음).
- 커버 이미지를 배경(`background-size:cover`)으로 깔고 하단 스크림으로 제목 가독 확보.
- 상단 좌측 `✦ 오늘의 글` 뱃지, 하단 제목 + 푸터(출처 · 읽음 수 · 인사이트 수).
- 커버 없으면 **기업 브랜드색 그라디언트 + 옅은 로고**로 폴백(다크 대비 유지).

### 인기 있는 글 (`popular-grid`) — 2열 그리드
**인사이트 많은 상위 8개**(오늘의 글 제외)를 **2열 그리드**로(세로 스크롤). 카드는 커버 카드(`fcard`) 통일 메타를 쓰되 좁은 폭에 맞춰 제목 15px.

### 큐레이션 로우 (`curation-row`) — 북마크 / 기업별 공통
가로 스냅 스와이프 + 섹션 헤더 우측 **전체보기** 버튼. 두 섹션에 재사용한다.
- **북마크 글**: 내가 북마크한 글. 없으면 → 아래 '빈 상태 / 인증 안내'.
- **기업별 글**: 기업 헤더(로고+이름+즐겨찾기) 아래 해당 기업 최신 카드가 흐른다.
- 카드: 커버 카드(`fcard`, 각짐), **통일 카드 메타**, `flex 0 0 76%` peek.

### 리스트 로우 (`lrow`) — 검색·마이 (밀도형)
롱블랙 '지난 노트' 스타일. 세로 목록에서 밀도를 높이는 **통일 카드 메타의 리스트 변형**이다. 커버 카드와 같은 메타·색·타이포를 쓰되 이미지를 작게 줄여 한 화면에 많이 담는다.
- **좌: 썸네일** — 56px 정사각(**각짐**). 커버 이미지(첫 `::img::`) 또는 **기업 브랜드색 플레이스홀더 + 로고**(커버 없을 때).
- **우: 제목**(`{typography.card-title}`, 2줄 클램프) + **메타 라인**(작성자/출처 · 읽음 수 · 인사이트 수 · 등록일).
- **우측 끝: 북마크 토글**.
- 행: 카드 면 없이 **플랫 목록**, 사이 `{colors.hairline}` 1px 또는 8px 간격.
- 커버 카드와 **동일 메타·토큰** — 밀도만 다르다(큰 이미지 강요 금지).

### 인사이트 카드 (`ins-card`) — 인사이트 탭 (통일 카드 예외)
인사이트 탭은 "글"이 아니라 **사람들의 감상(리뷰)**을 보여주므로 통일 카드(커버/리스트) 대상이 **아니다**. 같은 토큰을 쓰고 **작은 글 썸네일**을 얹어 리스트 로우와 라임을 맞춘다.
- 상단: **좌 글 썸네일 40px** + (작성자 아바타·이름 · 작성일) + 글 제목(뮤트, 상세로 링크).
- **Q&A 전체**(3문항): 길면 `ins-qa.clamp`로 페이드 클램프 + **더보기/접기**(`ins-more`).
- 하단(`ins-foot`): 더보기 · 우측 **댓글 수**.
- **카드 클릭 → `/posts/[id]?insight=<reviewId>`** : 상세로 이동하며 **해당 인사이트로 스크롤·강조(포커싱)**.
- 글 메타(북마크·읽음 수·인사이트 수)는 두지 않는다 — 감상 피드이지 글 목록이 아니다.
- 탭: `utabs` 전체 / 북마크(내가 북마크한 글에 달린 인사이트).

### Company Logo (`clogo`)
실제 기업 로고(인라인 SVG 마크: 토스·카카오·네이버·배민·당근·라인). 미매칭 시 컬러 이니셜 타일 폴백. 헤더 38px / 카드 26px / 인라인 20px.

### Company Header (`comprow`)
로고 + **기업명** + **즐겨찾기 별**(이름 옆). 도메인 표기 없음. 활성 별은 코랄.

### AI / Author Card
- **`ai-card`**: AI 3문답. bg `{colors.surface}`. `✦`(코랄) 아이브로우 + Q/A 쌍.
- **`author-card`**: 직접 등록 작성자. bg `{colors.surface}`. 아바타+이름 + `직접 등록`(코랄) 배지.

### 원문 리더 (`article` / `artblk`) — 구조 보존형
원문을 **평문이 아니라 구조형 블록**으로 렌더해 위계를 살린다. `posts.body`는 타입 접두어 배열(`::h2::`/`::h3::`/`::p::`/`::li::`/`::quote::`/`::code::`/`::img::`/`::cap::`).
- **타이포 위계**: 헤딩(h2 20px/700 · h3 17px/700) / 문단(16px/1.78 charcoal) / 목록(코랄 불릿) / 인용(좌측 하드라인 + 이탤릭) / 코드(모노 + surface) / 이미지(full-width, 각짐) / 캡션(중앙 뮤트).
- **원문 링크**: 섹션 헤더 우측 `원문 링크 ↗`(파랑) — parsed 글도 항상 제공.
- **문단 단위 하이라이트/메모**(`artblk`): 문단 탭 → 하이라이트(코랄 밑줄면) / 메모. 메모는 **문단의 코랄 아이콘 → 모달**로 보기·수정·삭제. **나만 보기**.
- 이미지 없이 못 불러온 글은 원문 링크 카드(`linkcard`)만.

### 상세 인사이트 & 댓글 (`review` / `cmt`)
- **인사이트(리뷰) 카드**: 작성자 + 작성일 + 3문항(Q/A). 내 인사이트면 우측 **⋯ 점 메뉴(`kebab`) → 수정**(드로어). 내 인사이트 없으면 상단 `인사이트 쓰기` 버튼.
- **인라인 "댓글 및 토론"**(`cmt-sec`): 시트가 아니라 **카드 하단에 상시 펼침**.
  - 입력창(`cmt-input`) + `등록`(검정 알약).
  - 댓글(`cmt`): 아바타 + 이름 + `작성자` 배지 + 시간 / 본문 / **답글 달기** · **좋아요(하트, 활성 코랄)+수**.
  - **대댓글**(`cmt.reply`): 34px 들여쓰기. 1단계.
- 포커싱: `?insight=<id>`로 들어오면 해당 리뷰로 스크롤 + 코랄 펄스(`rv-focus`).

### Chips & Tabs
- **`utabs`(언더라인 탭)**: **피드·인사이트** 상단 전체/북마크. 활성 = 검정 텍스트 + 2px 하단바.
- **`seg`(알약 세그먼트)**: **마이 3탭**(인사이트/댓글/하이라이트, 개수 표시)·알림 탭 등. 활성 검정.
- **`chip`**: 비활성 bg `{colors.canvas}` + `1px {colors.hairline}` + `{colors.text}`. 활성 bg `{colors.ink}` + `{colors.on-primary}`.
- **`chip-cat`**(아이브로우): 카테고리별 파스텔 bg/fg.

### Badges — 알약 (Pretendard)
- **`badge-new`**: bg `{colors.cat-ai-fg}` 코랄 / `#fff`.
- **`badge-read`**: bg `{colors.surface}` / `{colors.steel-text}`.
- **`badge-ok`**: bg `{colors.success-bg}` / `{colors.success-text}`.

### Section Divider (`section-divider`) — *현재 미사용*
과거 8px surface 구분선. **홈은 구분선 대신 `hsec` 큰 제목+설명+56px 여백**으로 나눈다. 클래스는 남아있으나 홈에서 쓰지 않는다.

### Loading (`spinner` / `PageSkeleton`)
전역 로딩 UI. 라우트 전환 시 **즉시 피드백**을 줘 "지연 = 오류" 오인을 막는다. 각 주요 라우트에 `loading.tsx` 폴백 배치.
- **`spinner`**: 코랄 회전 링(2.5px, `--card-strong` 트랙 + `--coral` 헤드). 중앙 배치 `loading-screen` 또는 클라이언트 액션 인라인.
- **`PageSkeleton`**: 앱바 라인 + 카드 스켈레톤(shimmer). 리스트형 페이지의 Suspense 폴백.
- 컴포넌트: `src/components/Loading.tsx` (기본 export = 중앙 스피너).

### Confirm Dialog (`confirm-box`)
하단 고정 확인 다이얼로그 + `scrim`. 파괴적 액션 확인용.
- **삭제 시 개수 명시**: 직접 등록 글 삭제 확인에는 달린 **인사이트 N개·댓글 M개**를 문구에 노출("…삭제하면 모두 함께 사라져요"). 참여가 없으면 일반 문구.
- 버튼: `button-outline`(취소) + `button-danger`(삭제, 진행 중 "삭제 중…").

### Inputs / Search
- **`input`**: bg `{colors.canvas}`, `1px {colors.hairline}`, `{rounded.input}`, focus 테두리 `{colors.ink}`.
- **`searchbar`**: bg `{colors.surface}`, `{rounded.full}`. **위치는 기존 유지**(앱바 아래 독립 행).

### My — 프로필 / 로그아웃
프로필 행: 아바타 + 이름/역할 + **로그아웃(`logout-sm`)을 우측에 소형 아웃라인 pill**로. 하단 대형 버튼 아님.

### 빈 상태 / 인증 안내
- **북마크 없음**: 홈 '북마크 글' 섹션이 비면 큐레이션 카드 대신 안내 — "북마크한 글이 여기 모여요 · 마음에 드는 글에 북마크를 눌러보세요" + 동사형 버튼(피드로 이동, 선택).
- **비로그인 북마크 시도**: 로그아웃 상태에서 카드/상세의 북마크 버튼을 누르면 저장 대신 **로그인 안내**(구글 로그인 유도 시트/토스트). 다른 개인화·파괴적 액션도 동일 패턴.

### Navigation — **기존 유지**
- **앱바**: 로고(insight**.** — 점 코랄) + 우측 **알림 벨**(유지). 하단 `1px {colors.hairline}`.
- **탭바**: 하단 고정 **4탭 — 홈 / 피드 / 인사이트 / 마이**(유지, 변경 안 함). 활성 `{colors.ink}`, 비활성 `{colors.steel-text}`.
- **아이콘**: 앱 자체 SVG 아이콘셋(`Icon.tsx`) 유지. 레퍼런스의 Material Symbols는 참고용.

## Do's and Don'ts

### Do
- 대표 CTA는 검정 알약.
- 코랄은 NEW 뱃지·FAB·활성 즐겨찾기/좋아요·원문 하이라이트·오늘의 글 뱃지에만.
- 홈은 오늘의 글(매거진 히어로) → 인기 있는 글(2열) → 북마크·기업(전체보기 스와이프) 순으로 성격을 구분. **큰 제목+설명+56px 여백**.
- 모든 **글** 카드는 통일 카드 메타를 같은 순서로 — 커버 카드(홈·피드)든 리스트 로우(검색·마이)든 한 가족.
- **카드·이미지·히어로는 각짐(0)**, 버튼·칩·탭·배지는 알약(`{rounded.full}`).
- 모든 텍스트 Pretendard. 카드/원문 제목은 700 near-black.
- 기업은 실제 로고 마크로.

### Don't
- 코랄·파랑을 본문/넓은 면에 쓰지 말 것.
- **버튼·칩·탭·배지를 각지게 하지 말 것**(알약 유지). 반대로 **카드·이미지에 라운드를 주지 말 것**(각짐 유지).
- 기업 필터 칩에 **점·보더 링으로 선택 표시하지 말 것**(선택은 채움으로 — 크기 변화 유발 금지).
- **DM Sans·JetBrains Mono 등 별도 서체 도입 금지** — 전부 Pretendard.
- 알림 벨·하단 탭바를 리프레시 명목으로 바꾸지 말 것.
- 커버 카드에 테두리·그림자 넣지 말 것(완전 플랫).
- 파랑을 주요 CTA로 되돌리지 말 것.

## Responsive
- 기본 모바일(480px 셸). 데스크톱도 480px 중앙 컬럼.
- 오늘의 글: 매거진 히어로(큰 커버 이미지, min-height 360px) full-bleed. 인기 있는 글: 2열 그리드(row-gap 26px). 큐레이션 로우(북마크·기업): `flex 0 0 76%` peek 스와이프(gap 14px) + 전체보기.
- FAB·탭바는 `env(safe-area-inset-bottom)` 고려. 터치 타깃 최소 44px.

## Known Gaps / Notes
- **PWA**: `manifest.ts`(standalone·portrait, theme `#161616`) + 앱 아이콘(`icon.svg`, `icon-192/512.png`, `apple-icon.png` 180). 폰 "홈 화면에 추가" 시 앱처럼 설치. 아이콘 = 검정 타일 + 흰 "i" + 코랄 점.
- **폰트**: Pretendard만 CDN 로드. DM Sans/JetBrains Mono 링크 제거.
- **로고 자산**: 기업별 SVG 심볼 맵(`PostCard`), 신규 기업은 이니셜 폴백.
- **다크 모드**: 대비 유지 원칙만. 정식 팔레트 추후.
- **애니메이션**: 상태 전환 150–200ms ease. 카드 rise 유지.

## Iteration Guide
1. 한 번에 한 컴포넌트씩. `globals.css` 토큰 → 클래스 순.
2. 토큰명 직접 참조(`{colors.ink}`, `{rounded.full}`).
3. 새 변형은 `-active`/`-disabled` 별도 항목.
4. 본문 `{typography.body}`, 강조는 weight. 헤드라인 appbar→display-title→hero→card-title.
5. 브랜드색이 일반 버튼/면에 등장하면 "그 자리를 벌었는가" 자문.
