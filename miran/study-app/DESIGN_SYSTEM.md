# distill 디자인 시스템 (DESIGN_SYSTEM.md)

이 문서는 앱 전체의 **시각 언어(비주얼) 정본**입니다. 레퍼런스(착한의사·DB손해보험 다이렉트·라이프ON)의
"깔끔·여백·라운드 카드·아이콘 그리드·칩 필터·부드러운 강조" 패턴을 distill 브랜드로 정리했습니다.

> **불변 규칙**: 이 개편은 **시각(색·간격·라운드·그림자·타이포·칩/카드 스타일)만** 바꿉니다.
> **표출 정보 항목·화면 뷰 방식(레이아웃 구조·순서)은 절대 변경하지 않습니다.**

---

## 0. 디자인 원칙
1. **한 번에 하나에 집중** — 화면당 강조 요소 1개. 나머지는 조용하게(중립색).
2. **여백이 위계다** — 요소 사이 넉넉한 간격(섹션 24, 카드 안 14~16).
3. **부드러운 라운드** — 카드 16, 칩 pill(999). 날카로운 모서리 없음.
4. **강조는 절제** — 인디고 1색 강조 + 주제 파스텔. 색을 남발하지 않음.
5. **스캔 가능** — 섹션 헤더(친근한 문장) → 가로 캐러셀/리스트. 카드로 끊어 읽기.

---

## 1. 컬러 (토큰: `src/theme/colors.ts`)
강조는 **인디고**. 라이트/다크 모두 토큰으로만 사용(하드코딩 hex 금지).

| 역할 | 라이트 | 다크 |
|---|---|---|
| primary(강조) | `#4F46E5` | `#7C83FF` |
| primaryTint(선택 배경) | `#EEF0FE` | `#232445` |
| actionOn(강조 위 글자) | `#FFFFFF` | `#0F1115` |
| textPrimary / Secondary / Muted | `#111827` / `#4B5563` / `#9CA3AF` | `#F3F4F6` / `#C2C7D0` / `#7C8494` |
| surfacePage(바탕) | `#F9FAFB` | `#0F1115` |
| surfaceCard(카드) | `#FFFFFF` | `#171A21` |
| surfaceSunken(입력·옅은 블록) | `#F3F4F6` | `#1F232C` |
| hairline(구분선) | `#EAECEF` | `#2A2F3A` |
| hot(알림 점·강조 포인트) | `#DE6A4E` | `#E67E64` |

**주제 파스텔(7색, 칩)** — `TOPIC_META`: 각 주제는 `color`(글자) + `tint`(배경). 예: 개발 `#2F5FC9`/`#E9F0FB`.
칩은 항상 tint 배경 + color 글자. **주제 색은 강조색(primary)과 별개** — 의미 색으로만.

## 2. 타이포그래피 (`dtype`)
Pretendard(미번들 시 시스템). **lineHeight를 fontSize보다 충분히 크게**(한글 잘림 방지).

| 토큰 | size / line / weight | 용도 |
|---|---|---|
| display | 28 / 34 / 800 | 인사말·화면 타이틀 |
| titleL | 22 / 28 / 700 | 히어로 제목·프로필 이름 |
| title | 18 / 24 / 700 | 섹션 헤더 |
| cardTitle | 16 / 22 / 600 | 카드 제목 |
| body | 15 / 24 / 400 | 본문 |
| bodyS | 13.5 / 20 / 400 | 보조 본문·부제 |
| meta | 12 / 16 / 500 | 날짜·수치 메타 |
| label | 12 / 14 / 700 | 아주 작은 라벨(칩엔 아래 규칙 사용) |

> **칩·셀 텍스트 규칙**: `label`을 그대로 키우지 말 것. 칩은 `fontSize 13, lineHeight 18, weight 700`,
> 아이콘 셀은 `fontSize 11.5, lineHeight 15`. (fontSize>lineHeight로 한글이 잘리던 버그 방지)

## 3. 간격·라운드·그림자
- **간격 스케일**: 4 / 8 / 12 / 16 / 24 / 32. 화면 좌우 패딩 **16**. 섹션 간 **22~24**.
- **라운드**: 카드 **16**, 큰 시트 **20**(상단만), 칩/버튼 **pill(999)**, 입력 **12**, 작은 썸네일 **10~12**.
- **그림자(카드 위로 뜨는 요소만)**: FAB·바텀시트·드롭다운 패널.
  `shadowColor #000, opacity 0.18, radius 12, offset (0,6), elevation 8`.
  일반 카드는 그림자 대신 **1px hairline 보더**로 구분(플랫·깔끔).

## 4. 핵심 컴포넌트

### 4.1 아이콘 그리드 (서비스 모아보기 — 착한의사/DB 아이콘 그리드)
- **카드 없이** 아이콘(파비콘) + 이름만. 셀 정렬 center, gap 8.
- 2행 가로 스와이프. 셀 폭 ≈ `(W-32)/4.4`(다음 칸 살짝 노출 → 스와이프 유도).
- 아이콘 44px, 이름 `11.5/15/700`, 1줄 말줄임.

### 4.2 칩 필터 바 (라이프ON "ALL/전체 + 카테고리")
- 가로 스크롤 pill 칩. **맨 앞 "전체"**(선택 없을 때 채워짐=primary).
- 기업 칩 = 작은 파비콘(18) + 이름. 선택 시 `primaryTint` 배경 + `primary` 글자/보더.
- 칩: `paddingH 14, paddingV 8, radius 999, 보더 1`. 텍스트 `13/18/700`.
- 컨테이너 `paddingH 16, paddingV 8, gap 8, alignItems center`(잘림 방지).

### 4.3 카드(아티클)
- 흰 카드 + `hairline` 보더 + radius 16. 썸네일 위(16:9) / 리스트 행은 좌측 84 정사각.
- 구성 유지: [주제칩] → 제목(cardTitle, 2줄) → 메타라인(파비콘18 + 기업·날짜·읽기시간).
- 썸네일 없으면 **브랜드 로고로 채움**(빈칸 방지). 이미지 URI는 `safeImageUri`로 인코딩.

### 4.4 섹션 헤더
- 제목(title) + 선택적 부제(bodyS, muted). marginBottom 12. 좌측 정렬.
- **친근한 문장형 타이틀**(예: "지금 많이 보는 글이에요", "OOO님이 관심 있을 글이에요").

### 4.5 바텀시트 / 드롭다운 패널
- 바텀시트: 하단 정렬, 상단만 radius 20, `paddingH 20, paddingBottom 30~34`.
  헤더(title + X) → 내용 → 하단 강조 버튼(primary, radius 12, paddingV 14~15).
- 상단 드롭다운(기업 전환 등): 상단 앵커, 좌우 margin 10, 하단 라운드 18 + 그림자.

### 4.6 탭
- **하단 탭(4개)**: 홈·피드·인사이트·마이. 아이콘 + 라벨(11.5/700). 활성 primary.
  높이 70, paddingTop 8, paddingBottom 12. 배경 `surfaceNav` + 상단 hairline.
- **상단 서브탭(인사이트/커뮤니티)**: 텍스트 탭 + 활성 하단 2px 바(primary).
- **필터 탭/칩**: §4.2.

### 4.7 FAB · 버튼 · 입력
- FAB: 56 원형, primary, 그림자(§3). **커뮤니티에서만**.
- 주요 버튼: primary 배경, actionOn 글자, radius 12/pill, paddingV 14.
  보조 버튼: surfaceCard + hairline 보더.
- 검색바/입력: surfaceSunken 배경, radius 12, height 44~46, 좌측 아이콘.

### 4.8 아바타 · 로고
- 아바타: 이름 해시 배경(`hsl(h,34%,44%)`), 원형.
- 서비스 로고: 브랜드 파비콘(`brandIcon.ts`, 네이버 계열 통일·Medium 보정), 실패 시 브랜드색+이니셜.

### 4.9 상태(빈/로딩/에러)
- 로딩: 중앙 스피너 + "불러오는 중…". 빈: 제목 + 힌트 1줄. 에러: 재시도 버튼.
- **조건부 섹션**: 데이터 없으면 섹션 자체를 숨김(홈 큐레이션 규칙).

## 5. 화면별 적용 노트 (정보·순서 유지, 시각만)
- **홈**: 인사말+🔔 → 검색바 → (큐레이션 순서 그대로) 각 섹션은 §4.4 헤더 + §4.1/§4.3 카드.
- **피드**: 제목+🔍 → **기업 칩 바(§4.2)** → 주제 칩 → 개수/정렬 → 카드 리스트.
- **인사이트**: 제목+🔍 → 서브탭 → (인사이트) 기업 칩+주제+정렬+인사이트 카드 / (커뮤니티) 리스트 + FAB.
- **마이**: 프로필(+🔍⚙) → 관심 기업 → 내 활동 칩 세그먼트 → 목록. (캘린더 요소는 활동 섹션 상단.)
- **기업 상세**: 헤더 기업명 셀렉트 → 브랜드 히어로+즐겨찾기 → 인기글 캐러셀 → 주제 칩+최신.
- **글 상세**: 히어로 → 메타(공유·북마크) → 제목 → 태그 → 출처 → 원문보기 → [원문/인사이트] 탭.
  인사이트는 **§InsightBody(타이틀+내용 블록)**. 좋아요는 인사이트·댓글에만.

## 6. 접근성·다크모드
- 텍스트 대비 AA 이상. 터치 타깃 ≥ 40. hitSlop로 작은 아이콘 보완.
- 모든 색은 토큰 → 다크모드 자동 대응. 하드코딩 hex는 흰색 글자(#fff) 등 극소수만.
