# 폰트 (Pretendard)

여기에 Pretendard 글꼴 파일을 넣으세요:

- `Pretendard-Regular.otf` (필수)
- `Pretendard-SemiBold.otf` (선택)
- `Pretendard-Bold.otf` (선택)

받는 곳: https://github.com/orioncactus/pretendard (releases 의 `Pretendard-x.x.x.zip` 안 `public/static/`)

파일을 넣은 뒤 `src/theme/fonts.ts` 의 `useFonts` 주석을 해제하면 앱 전역에
Pretendard 가 적용됩니다. (dev/README §2)
