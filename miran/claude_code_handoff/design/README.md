# Handoff: 기획 스터디 (Gihoek Study) — 모바일 앱

## Overview
**기획 스터디**는 기획(product/service planning)에 도움되는 글을 함께 읽고, 요일별로 공유하며, 주차별로 토론하는 스터디 커뮤니티 모바일 앱입니다. 사용자는 여러 스터디에 참여하고(초대 코드로 참여/생성), 각 스터디 안에서 **달력**으로 날짜별 공유 글을 보고, **이번 주** 요일별 큐레이션을 확인하며, **토론**에 참여하고, **마이페이지**에서 프로필·표시 설정을 관리합니다.

핵심 사용자 흐름:
- **내 스터디(홈)** → 스터디 선택 → 스터디 내부(달력 / 이번 주 / 토론 / 마이페이지 탭)
- 스터디 **생성**(무작위 6자 초대 코드 발급) / 초대 **코드로 참여**
- 공유 글: **링크 공유**(URL + 게시글) 또는 **직접 작성**, 상세에서 AI 요약 · 좋아요 · 댓글
- 토론: 주차별 목록 → 상세(여는 글 + 스레드 답글 + 방장 결론 고정)

## About the Design Files
이 번들의 파일은 **HTML/JSX로 만든 디자인 레퍼런스**입니다 — 의도한 외형과 동작을 보여주는 프로토타입이며, 그대로 복사해 배포할 프로덕션 코드가 아닙니다. 작업은 이 디자인을 **대상 코드베이스의 기존 환경**(React Native / Flutter / SwiftUI / 웹 등)에서 그 환경의 관례·라이브러리로 **재현**하는 것입니다. 아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 골라 구현하세요.

프로토타입은 순수 브라우저(React 18 UMD + Babel standalone)에서 도는 인터랙티브 목업으로, iOS 프레임(`ios-frame.jsx`, 812pt 기준) 안에 렌더됩니다. 상태는 컴포넌트 `useState`로만 관리되는 목업이며 실제 백엔드/영속성은 없습니다.

## Fidelity
**High-fidelity (hifi).** 최종 색상·타이포그래피·간격·라운드·인터랙션이 확정된 픽셀 단위 목업입니다. 아래 디자인 토큰과 화면 명세의 정확한 수치(hex, px)를 그대로 사용해 대상 코드베이스의 컴포넌트로 재현하세요. 단, 값을 4/8 그리드로 반올림하지 말고 명시된 수치를 그대로 쓰세요.

디자인 언어: **Slack에서 영감받은 어버진(aubergine) 시스템** — 딥 퍼플 프라이머리(#4a154b), 크림/라벤더 보조 표면, 90px 알약 버튼, 인라인 블루 링크. (design_system/ 폴더의 원본 토큰 CSS 참조. 앱 화면은 `index.html`의 `.app-scope`에서 이 토큰들을 어버진으로 오버라이드해 사용합니다 — 아래 Design Tokens가 실제 적용값입니다.)

## Screens / Views

앱은 **네비게이션 스택 + 스터디 내부 하단 탭바** 구조입니다. 라우터 상태는 `{ name, studyId, discId, shareId }` 하나로 관리(`index.html`의 `App`). 스터디 내부 화면(cal/weekly/disclist/mypage 및 그 하위)에서만 상단 바 + 하단 탭바가 보입니다.

### 1. MyStudies — 내 스터디 (루트/홈)
- **Purpose**: 참여 중인 스터디 목록 확인, 스터디 만들기/코드로 참여 진입.
- **Layout**: 세로 스택. 상단 헤더(페이지 이모지 📚 + 제목 "내 스터디" + 우측 고스트 아이콘 2개: 알림 벨, 설정 톱니), 그 아래 검색 필드, "내 스터디" 섹션 라벨 + 목록(행 리스트), 각 행 탭 시 해당 스터디 달력으로 이동.
- **Components**:
  - **스터디 행(np-row)**: 좌측 40×40 라운드(8px) 아바타 타일(스터디명 첫 글자, 배경색은 이름 해시 hsl(h,34%,44%) — 초록/청록/자주 등 컬러풀), 제목(Pretendard 16px/600, letter-spacing -0.3px), 그 아래 💬 이번 주 토론 제목(13px, 말줄임 1줄), 우측 상단 멤버수(예 "14명"), 우측 **안읽음 빨간 점**(8×8, #e03e3e, 숫자 아님). 방장 스터디는 제목 옆 "방장" 태그(cream #f4ede4 배경 + 어버진 텍스트, 라운드 4px, 11px/600). 행 hover 시 배경 `--surface-page-alt`.
  - **검색 필드**: 라벤더(#f9f0ff) 채움, 라운드 8px, 좌측 돋보기 아이콘 + placeholder "스터디 검색 또는 점프하기".
  - **CTA(하단, 목록 아래)**: "+ 새 스터디 만들기"(어버진 채움 알약) / "초대 코드로 참여하기"(라벤더 채움 버튼). ※ 현재 앱에서는 헤더 "+" 및 스터디 관리 화면으로도 진입.
- **Copy**: "내 스터디", "워크스페이스 · 3", "방장", "N명".

### 2. CreateStudy — 새 스터디 만들기
- **Purpose**: 이름·소개 입력 후 무작위 초대 코드 발급.
- **Layout**: 상단 "‹ 취소" → 제목 → 이름 input, 소개 textarea → 하단 "만들고 코드 생성" 버튼. 생성 후 **결과 화면**으로 전환: 성공 체크 원(64px, 어버진 10% 틴트 배경), "스터디를 만들었어요", 점선 테두리 코드 박스(40px/700, letter-spacing 6px), "코드 복사" / "완료".
- **Components**: text input(흰 배경, 1px #e6e6e6, 라운드 8px, 13px 라벨/600), textarea 동일. 코드 생성: 혼동 문자 제외 32자 세트에서 6자(`ABCDEFGHJKLMNPQRSTUVWXYZ23456789`).

### 3. JoinStudy — 초대 코드로 참여
- **Purpose**: 6자 코드 입력 → 일치 스터디로 입장.
- **Layout**: 상단 "‹ 취소" → 제목/설명 → 큰 코드 input(가운데 정렬, 32px/700, letter-spacing 10px, 대문자화, maxLength 6) → 하단 "참여하기"(6자 미만이면 비활성). 불일치 시 에러 문구(#cc4117).
- **Copy**: "초대 코드로 참여", "방장에게 받은 6자리 코드를 입력하세요", "예시 코드: K7F2QX · UX9M3T · PM4W8R", "존재하지 않는 코드예요. 다시 확인해주세요."

### 4. StudyCalendar — 달력 (스터디 내부, 탭 1)
- **Purpose**: 월 달력에서 날짜별 공유 글 개수를 점으로 보고, 선택한 날의 글 목록 확인.
- **Layout**: 상단 "YYYY. M" + 월 이동 고스트 화살표(‹ ›). 7열 요일 헤더(일=적색 #c0392b, 토=어버진, 나머지 뮤트). 날짜 그리드(각 셀 높이 52px): 선택일은 어버진 채움 원(28px), 오늘은 어버진 텍스트, 글 있는 날은 하단 6px 어버진 점. 아래 구분선 후 "M월 D일 (요일)" + "+ 글 공유"(텍스트 버튼) + 공유 글 카드 목록(최신순).
- **공유 글 카드(np-card)**: 라벤더(#f9f0ff) 배경, 테두리 없음, 라운드 10px, padding 15px. 상단 30px 원형 아바타(hsl 이름색) + 공유자명(14px/600) + "역할 · 출처(또는 직접 작성)". 제목(16px/600, 1줄 말줄임), 메모/본문 프리뷰(13.5px, 2줄 클램프, 높이 3em 고정), 하단 ♥ 좋아요수 · 댓글수. **주의: URL/도메인 주소 텍스트는 표시하지 않음**(출처 사이트명만).

### 5. Weekly — 이번 주 (탭 2)
- **Purpose**: 이번 주 월~일 요일 선택 후 해당 요일 공유 글 확인(요일마다 스택하지 않아 화면 높이 일정).
- **Layout**: 상단 "N월 N째 주" + "+ 글 공유". 주간 스트립(라벤더 블록, 라운드 10px): 7개 요일 셀(요일 라벨 + 날짜 원 + 글 있으면 점, 선택 요일 어버진 채움). 아래 "M월 D일 (요일)" + 공유수, 검색 필드(라벤더 채움), 공유 글 카드 목록(StudyCalendar와 동일 카드).

### 6. DiscussionList — 토론 목록 (탭 3)
- **Purpose**: 월별 주차 토론 목록, 미참여 알림, 토론 생성, 검색.
- **Layout**: 상단 **미참여 콜아웃**(진행 중 토론에 내 의견 없을 때; cream #f4ede4 배경, 좌측 어버진 점, "참여 ›"). 월 이동 고스트(‹ 7월 ›) + "+ 토론"(어버진 채움, 소형). 검색 필드(라벤더 채움). 토론 행 리스트.
- **토론 행(np-row)**: 좌측 38px 라운드(8px) 아이콘 타일(말풍선 svg; 진행 중이면 cream 배경+어버진, 아니면 라벤더+뮤트), 우측: 주차 라벨(11.5px 뮤트) + "진행 중" 태그(어버진 pill 태그) + 미참여 빨간 점, 제목(15.5px/600), 프롬프트(13px, 1줄 클램프), "💬 의견 N", 우측 chevron.

### 7. DiscussionDetail — 토론 상세 (스레드)
- **Purpose**: 여는 글(주최자 메시지) + 스레드 답글 + 방장이 의견 하나를 "결론 고정".
- **Layout**: 상단 채널형 헤더("토론 · 주차" 키커 + 제목). Slack 메시지 행 스타일:
  - **여는 글**: 라운드-사각 아바타 + 주최자명 + "주최" 배지(라벤더 배경, 라운드 3px, 어버진) + 역할·시간, 본문 문단, (링크형이면) 북마크형 언퍼를 카드 + AI 요약 블록. 액션 행: **👍 좋아요{수}** / **↩ 답글** (이모지 리액션·피커 없음, 좋아요만). 방장은 각 의견에 "📌 결론 고정" 토글.
  - **결론 고정**: 상단에 고정 카드로 승격 표시.
  - **댓글/답글**: 메시지 행, 인용(quote) 표시(좌측 3px 바 + 원 작성자·텍스트 2줄 클램프). hover 시 `--color-divider-soft`.
  - **하단 입력창(sticky)**: 답글 대상 있으면 상단 라벤더 칩(대상 표시 + ✕), 테두리 라운드 10px 입력 박스 + 우측 30px 전송 버튼(활성 시 어버진, 비활성 시 parchment).

### 8. ShareDetail — 공유 글 상세 (Slack 메시지형)
- **Purpose**: 공유 글 원문 접근(링크는 버튼으로) + AI 요약 + 댓글.
- **Layout**: 채널 헤더("# 공유 글 · 출처" — **도메인/URL 텍스트 미표시**, 사이트명만; 제목). 공유자 메시지 행(라운드-사각 아바타 + 이름 + "역할 · 글을 공유했어요" + 메모 문단).
  - **링크 언퍼를**: 좌측 4px 어버진 바, 출처 사이트명, 제목(블루 링크 #1264a3), 설명 + 76×56 썸네일 자리, **"원문 열기 ↗"**(주소는 링크 뒤에 감춰짐, 텍스트 노출 안 함).
  - **AI 요약**: 라벤더 헤더("✨ AI 요약" + "요약하기" 버튼) → `window.claude.complete`로 한국어 요약 생성(핵심 2~3문장 + 불릿 3개). ※ 프로덕션에선 서버측 요약 API로 대체.
  - **직접 작성 글**: 본문 인라인 박스.
  - 액션: **👍 좋아요{수}**(토글). 댓글 divider("답글 N개") + 댓글 메시지 행(인용 지원) + 각 댓글 👍 좋아요 / ↩ 답글.
  - 하단 sticky 입력창(DiscussionDetail과 동일 패턴).

### 9. Members — 멤버 / 권한 / 공유 주기
- **Purpose**: 멤버 목록·역할, (방장) 관리, 공유 주기 설정, 스터디 나가기.
- **Layout**: 나(역할 배지) + 멤버 리스트(방장은 "내보내기" 소형 버튼). 공유 주기 선택(칩). 하단 "스터디 나가기"(방장은 "스터디 삭제하고 나가기", 적색 테두리).

### 10. Notifications — 알림 센터
- **Purpose**: 미참여 토론 + 최근 활동(공유/댓글/신규 멤버) 모아보기.
- **Layout**: "미참여" 항목(참여하기 ›) + "최근 활동" 리스트, 항목 탭 시 해당 화면 이동.

### 11. CreateShare — 글 공유 작성
- **Purpose**: ① 링크 공유(URL + 게시글 본문) 또는 ② 직접 작성(제목 + 본문), 요일 선택.
- **Layout**: 상단 모드 토글(링크/직접), URL input(링크형) 또는 제목 input, 본문 textarea, 요일 선택 칩, 하단 "공유하기"(어버진 알약). ※ 링크형 미리보기의 도메인은 표시하지 않음.

### 12. CreateDiscussion — 토론 만들기
- **Purpose**: 링크형/직접 작성 토론 생성, 주차 선택.
- **Layout**: 모드 토글, URL/제목, 여는 글 textarea, 주차 선택 칩, "토론 열기"(어버진 알약).

### 13. MyPage — 마이페이지 (탭 4)
- **Purpose**: 프로필(이름/직급) 표시·편집 진입, 표시(다크/라이트) 설정, 스터디 관리·나가기.
- **Layout**: 프로필 헤더(아바타 + 이름 + 직급, 미설정 시 "게스트"), 항목 리스트(프로필 편집, 표시 설정 등), 하단 스터디 나가기.

### 14. ProfileEdit / DisplaySettings / StudyManage
- **ProfileEdit**: 이름·직급 input 편집. 입력한 직급이 내가 쓴 글·댓글의 역할로 반영.
- **DisplaySettings**: 라이트/다크 모드 선택(카드형 토글). 다크는 `.app-dark` 토큰셋으로 전체 오버라이드.
- **StudyManage**: 방장 스터디 수정/삭제, 초대 코드 재발급/만료, 새 스터디 만들기.

## Interactions & Behavior
- **네비게이션**: `go(name, studyId?, discId?/shareId?)`로 라우팅. 스터디 내부는 하단 탭바(달력/이번 주/토론/마이페이지). 상세 화면은 상단 "‹" 뒤로. 화면 전환 시 스크롤 상단 리셋.
- **하단 탭바**: 스터디 내부에서만 노출, frosted 배경(`--tabbar-bg` rgba(255,255,255,0.94) + blur). 활성 탭은 어버진, 비활성은 뮤트. 아이콘은 인라인 SVG(달력/목록/말풍선/사람).
- **버튼 press**: 어버진 pill은 press 시 `--action-press`(#611f69). 리스트/카드 hover는 `--color-divider-soft`/`--surface-page-alt`.
- **좋아요**: 토글 시 카운트 ±1, 채움/외곽선 thumbs-up SVG 전환. (이모지 리액션 기능은 의도적으로 제외 — 👍 좋아요만.)
- **정렬**: 댓글/의견 등록순 ↔ 좋아요(공감)순 토글(세그먼트).
- **초대 코드**: 생성 시 무작위 6자, 참여 시 대문자화·6자 검증, 불일치 에러.
- **AI 요약**: `window.claude.complete({max_tokens, messages})` 호출(프로토타입 한정). 프로덕션은 서버 요약 엔드포인트로 교체.
- **다크 모드**: `.app-dark` 클래스로 토큰 오버라이드, 상태바 색 반전.
- **애니메이션**: 대부분 배경/필터 0.1~0.12s ease 트랜지션. 과한 모션 없음.
- **반응형**: 목업은 iOS 812pt 프레임 기준. 실제 구현은 대상 플랫폼 안전영역(상단 노치/다이내믹 아일랜드 → 상단 바 상단 여백 ~52pt) 고려.

## State Management
- **라우트**: `{ name, studyId, discId, shareId }` 단일 객체.
- **참여 여부**: `participated`(토론 id별 내 의견 작성 여부 → 미참여 점/알림 계산).
