# 구현 범위 (PRD 기준)

PRD(`../테크블로그_아카이빙_서비스_PRD_1.md`)의 오픈 이슈(10장)는 팀 논의가 필요한 항목이라 코드 안에 섞이지 않도록, 아래처럼 기본값을 정해 `feature flag`(환경변수)로 분리한다. 팀 논의 후 값만 바꾸면 된다.

> v0.2 기준(2026-08-06 회의 반영): 하단 탭이 홈/피드/토론/검색/마이 5탭으로 재편되고, 등록 노트가 "독후감(인상 깊은 부분/접목하고 싶은 방법/질문·토론 주제)"으로, 토론이 "독후감 기준 노출 + 댓글" 방식으로 바뀌었다.

## 포함 기능 (MVP + v1.1 전체)

- 하단탭(홈/피드/토론/검색/마이)
- 구글 로그인
- URL 기반 글 등록 + 필수 독후감(인상 깊은 부분/접목하고 싶은 방법/질문·토론 주제)
- 원문 본문 서비스 내 렌더링(Readability 추출 + sanitize-html 정제, 실패 시 원문 링크로 대체)
- 기업·태그 분류, 중복 URL 방지
- 삭제(작성자 본인 + 관리자)
- 글 상세: 의견 + 댓글(쓰레드형, 대댓글 1단계) + 멘션 + 이모지 리액션
- 토론: 독후감 기준 노출(인기/최신/추천 + 카테고리 필터) + 댓글 + 가벼운 참여 토글(참여 인원 표시, 신청/모집 절차 없음)
- 북마크(글 단위) + 부분 북마크(하이라이트)
- 하이라이트 + 개인 메모(나만 보기)
- 마이페이지(임시저장/내 글(독후감 기준)/내 댓글/북마크/하이라이트·메모/읽은 아티클)
- AI 요약(Gemini) — 문제/해결/디자이너·PM 관점 3항목 구조화
- 하이라이트 구간 AI 쉬운 설명(Groq)
- 검색(최근/추천(질문형)/급상승 검색어, 이후 태그/기업/작성자 복합 필터로 고도화)
- 자동 수집(크롤링) — 꾸준히 올리는 기업 대상, 2025-07-01 이후 글만
- 알림(좋아요한 기업의 새 글/내 독후감의 댓글/대댓글)
- 컬렉션(주제별 글 모음)

## 오픈 이슈 → 기본값 (feature flag)

| 오픈 이슈 | 기본값 | 환경변수 |
|---|---|---|
| 원문 본문 스냅샷 저장 여부 | 저장함 — Readability로 추출 + sanitize-html로 정제해 서비스 내 렌더링(확정) | `FEATURE_ORIGINAL_SNAPSHOT=true` |
| 하이라이트/메모 공개 범위 | 나만 보기(개인 전용, 확정) | `FEATURE_PUBLIC_HIGHLIGHTS=false` |
| 삭제 정책 | 즉시 삭제 + 확인 모달 (소프트 삭제는 이후 과제) | `FEATURE_SOFT_DELETE=false` |
| AI 무료 API 한도 초과 대응 | 에러 처리 + "잠시 후 다시 시도" 안내만 (폴백 전환 없음) | `FEATURE_AI_FALLBACK=false` |
| 서비스 이름(가칭) | 테크아카이브 (TechArchive) — 언제든 변경 가능 | `NEXT_PUBLIC_SERVICE_NAME=테크아카이브` |
| 웹/앱 우선 | 웹 우선 (Next.js, Vercel 배포) | — |
| 독후감 강제성 | 완전 필수(미작성 시 등록 불가) | `FEATURE_NOTE_REQUIRED=true` |
| 로그인 방식 | 구글 로그인만 지원(확정, 플래그 아님) | — |
| 콘텐츠 대상 기업 범위 | 꾸준히 올리는 기업만 (확정) | — |
| 과거 글 수집 범위 | 2025-07-01 이후 발행 글만 (확정) | — |

이 표의 값은 `.env.local`에 그대로 넣어 코드에서 참조한다.
