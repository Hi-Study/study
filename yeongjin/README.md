# 테크 블로그 아카이빙 서비스 (기획 단계)

팀원들이 국내 빅테크/스타트업 기술 블로그 글을 함께 모으고, 읽고, 이해하고, 토론할 수 있는 소규모 팀 전용 아카이빙 서비스입니다. 현재는 **PRD(v0.1) 작성이 완료된 기획 단계**이며, 아직 코드는 없습니다.

## 핵심 가치 제안
- **모은다**: 네이버/컬리/당근마켓/토스/우아한형제들/오늘의집 등 기술 블로그 글을 자동 수집 + 팀원 수동 등록으로 한 곳에 아카이빙
- **함께 읽는다**: 댓글, 인라인 하이라이트 의견, 토론 신청으로 혼자 읽는 글이 아니게 만든다
- **쉽게 읽는다**: AI 요약과 형광펜 기반 AI 쉬운 설명으로 어려운 글의 진입장벽을 낮춘다
- **다시 찾는다**: 북마크, 읽기 상태 추적, 개인 메모로 마이 라이브러리에서 다시 꺼내볼 수 있게 한다

## 서비스 개요

### 하단 탭바 (4개)
| 탭 | 역할 |
|---|---|
| 🧭 탐색 | 자동 수집 글 + 팀원 등록 글이 모이는 최신순 피드 |
| ✨ 큐레이션 | 관심 키워드 칩 선택 기반 추천 피드 |
| 🔍 검색 | 키워드/태그/회사/작성자 검색 |
| 👤 마이 (내 라이브러리) | 프로필, 활동 통계, 이어서 읽기, 북마크, 메모, 관심 키워드 설정 |

### 핵심 기능
- **콘텐츠 자동 수집**: 대상 회사 RSS 피드를 실시간에 가까운 주기(5~15분)로 폴링, 본문 전체를 자체 저장
- **글 등록/삭제**: 카테고리·URL만 필수, 등록 노트(핵심 인사이트/정리할 지식/적용할 점)는 권장·건너뛰기 가능. 삭제는 소프트 삭제 후 유예기간
- **댓글 & 토론 신청**: 가벼운 쓰레드형 댓글과, 별도로 논의 자리를 모으는 토론 신청 기능을 탭으로 분리
- **형광펜 + AI 쉬운 설명**: 하이라이트는 팀 공개 기본(개인 전용 토글 가능), 인라인 의견은 `내 의견`/`용어·개념 정리 필요` 유형 선택(선택 사항)
- **AI 요약**: Gemini/Groq 무료 티어 기반 비동기 요약 파이프라인 + 한도 초과 대응 전략
- **개인 메모**: 기본 비공개, 필요 시 "팀에 공개" 토글
- **읽기 상태 & 이어서 읽기**: 스크롤 90% 기준 자동 "다 읽음" 처리

세부 사양과 확정된 정책 전체 목록은 PRD 9장("정책 결정 사항 및 남은 오픈 이슈")을 참고하세요.

## 기술 스택 (예정, PRD 6장 기준)
- **Frontend**: Next.js (웹 우선 출시 확정)
- **Backend**: Node.js(NestJS) 또는 Python(FastAPI)
- **DB**: PostgreSQL
- **AI**: Gemini Flash/Flash-Lite(요약) + Groq(형광펜 실시간 설명) 무료 티어 조합
- **자동 수집**: RSS/Atom 폴링 스케줄러
