## 2. 화면별 정의

### 🏠 홈 — 큐레이션
- **상단**: 추천 글
- **중단**: 기업별 칩 (다중 선택)
- **하단**: 기업별 글 스와이프

### 📰 피드 — 전체 글
- 전체 피드이자, 기업 클릭 시 이동되는 페이지
- 기업 칩 표현 방식은 각자 고민
  - ⚠️ 이슈: 칩이 너무 많아지는 문제

### 📄 글 상세
- 의견
- 의견에 대한 댓글
- 하이라이트 + 메모 (나만 보기)
- **AI 요약**
  - 무슨 문제를 다뤘나?
  - 어떻게 해결했나?
  - 디자이너·PM 관점에서 무엇을 배울 수 있나?
- 키워드 태그

### ✍️ 글 등록
- URL
- 독후감
  - 인상 깊은 부분
  - 접목하고 싶은 방법
  - 질문 / 토론하고 싶은 것

### 💬 토론 — *우리 서비스의 핵심 가치*
- 독후감 기준으로 노출
- 독후감에 댓글 달기

### 🔍 검색 — 관심사를 쉽게 찾을 수 있게
- 최근 검색어
- 추천 검색어 (질문 느낌)
- 급상승 검색어

### 👤 마이
- 임시저장
- 내 글 (등록한 글 + 크롤링한 글 포함): 독후감 기준
- 내 댓글
- 북마크
- 하이라이트 / 메모
- 읽은 아티클
